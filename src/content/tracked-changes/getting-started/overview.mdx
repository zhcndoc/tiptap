将“Tracked Changes”扩展为协作编辑工作流启用建议模式。启用后，所有编辑都会以提议形式出现，可以被接受或拒绝，类似于文字处理软件中的变更跟踪。

## 功能

该扩展会跟踪七种类型的更改：

- **插入**（`add`）— 添加到文档中的新内容
- **删除**（`delete`）— 标记为删除的现有内容
- **替换**（`replace`）— 同时被删除并替换为新内容的内容
- **标记更改**（`markChange`）— 应用于现有文本的格式或其他标记级别的更改
- **块拆分**（`split`）— 按下 Enter 键添加的段落分隔
- **列表缩进**（`sink`）— 使用 Tab 键将列表项嵌套到更深一层
- **列表减少缩进**（`lift`）— 使用 Shift-Tab 将列表项向外移出一层

每条建议都包含元数据，包括创建者、创建时间和唯一标识符。

## 主要功能

- **建议模式** — 按用户切换跟踪的开启和关闭
- **接受和拒绝** — 单独、批量、按范围或按用户审阅建议
- **建议分组** — 连续编辑会自动合并为单个建议
- **块拆分跟踪** — 按下 Enter 会标记段落分隔符本身，同时保持文本可读
- **嵌套建议** — 待处理建议中的跨作者编辑会作为独立建议堆叠，而不会覆盖原建议
- **支持协作** — 适用于基于 Yjs 的实时协作
- **评论集成** — 将建议链接到评论线程，以支持审阅工作流
- **Atom 节点支持** — 跟踪图片、水平线和其他非文本内容的更改
- **表格支持** — 跟踪行、单元格和列的插入与删除，包括单元格选择
- **完整查询 API** — 以编程方式查找、筛选和检查建议
