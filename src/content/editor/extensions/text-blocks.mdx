## 使用场景

- **文档结构。** Heading 可添加最多六级标题，Paragraph 用于存放正文。
- **引用。** Blockquote 用 `blockquote` 标签渲染引用内容。
- **可折叠区域。** Details 使用 HTML `details` 标签，在摘要后显示或隐藏内容。
- **分隔。** Hard break 可在内容块中强制换行，Horizontal rule 会绘制分隔内容的横线。

## 工作原理

- **它们都是节点。** Document 是用于容纳其他节点的顶层节点，Text 用于存放纯文本。每个编辑器都需要 Document；任何文本内容都需要 Text，段落则需要 Paragraph。[节点和标记](/editor/core-concepts/nodes-and-marks)
- **StarterKit 自带其中大多数节点。** Blockquote、Document、Hard break、Heading、Horizontal rule、Paragraph 和 Text 属于 [StarterKit](/editor/extensions/functionality/starterkit)；Details 需要手动添加。
- **Details 还需要两个节点。** Details 需要与同一软件包中的 Details summary 和 Details content 配合使用。
- **Markdown 快捷输入。** 在行首输入 `# ` 可开始标题，输入 `> ` 可开始引用块，输入 `---` 可插入水平分隔线。[键盘快捷键](/editor/core-concepts/keyboard-shortcuts)
