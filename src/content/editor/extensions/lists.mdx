## 使用场景

- **项目符号。** Bullet list 会添加无序列表，并渲染为 `ul` 标签。
- **编号步骤。** Ordered list 会添加编号列表，并渲染为 `ol` 标签。
- **待办事项。** Task list 和 Task item 会添加任务，每项都带有可勾选的复选框。
- **编辑列表。** 在列表项开头按 Backspace 时，List keymap 会将内容提升到上一个列表项中。

## 工作原理

- **列表由两个节点组成。** Bullet list 和 Ordered list 容纳 List item，Task list 容纳 Task item。每种列表都需要对应的列表项节点。[节点和标记](/editor/core-concepts/nodes-and-marks)
- **List kit 将它们组合在一起。** [List kit](/editor/extensions/functionality/list-kit) 包含 Bullet list、List item、Ordered list、Task item、Task list 和 List keymap。
- **StarterKit 包含基础列表。** Bullet list、List item、Ordered list 和 List keymap 属于 [StarterKit](/editor/extensions/functionality/starterkit)；Task list 和 Task item 不包含在内。
- **快捷输入。** 在行首输入 `- ` 可开始项目符号列表，输入 `1. ` 可开始有序列表，输入 `[ ] ` 可开始任务列表。按 <kbd>Tab</kbd> 可缩进列表项，按 <kbd>Shift</kbd> + <kbd>Tab</kbd> 可将其提升。[键盘快捷键](/editor/core-concepts/keyboard-shortcuts)
