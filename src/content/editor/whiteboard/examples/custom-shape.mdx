React 和 Vue 中具有自定义形状的白板：React 或 Vue 组件绘制的投票卡。用户使用每张卡片上的按钮进行投票，并像其他形状一样选择、移动卡片并调整其大小。白板上方的按钮可添加新卡。请参阅[自定义形状](/editor/whiteboard/guides/custom-shapes)。
