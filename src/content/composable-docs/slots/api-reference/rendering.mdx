将 `BlockSlot` 和 `InlineSlot` 作为普通 Tiptap 节点扩展进行定制。将它们传给 `Slot`，即可保留命令、索引和验证行为。

## HTML 属性

```ts
Slot.configure({
  blockSlot: BlockSlot.configure({ HTMLAttributes: { class: 'block-field' } }),
  inlineSlot: InlineSlot.configure({ HTMLAttributes: { class: 'inline-field' } }),
})
```

- `HTMLAttributes` (`Record<string, string>`)：外层元素属性。默认值为 `{}`。
- 必需的 `data-slot-*` 属性优先于自定义属性。
- 软件包不提供工具栏、边框或颜色。请在应用中设置包装器样式。

### 序列化属性

| 属性               | 值                      | 用途                              |
| ------------------ | ----------------------- | --------------------------------- |
| `data-slot-kind`   | `'block'` 或 `'inline'` | 标识节点类型。                     |
| `data-slot-id`     | Slot ID                 | 保留标识。                        |
| `data-slot-config` | 转义后的 JSON            | 保留嵌入配置。                    |

块 Slot 的默认包装器是 `div`，行内 Slot 的默认包装器是 `span`。可访问名称使用 `config.label`，没有时回退到 ID。

### 仅视图属性

| 属性                    | 值                     | 用途                                   |
| ----------------------- | ---------------------- | -------------------------------------- |
| `data-slot-empty`       | `'true'` 或 `'false'`  | 设置空字段样式。                       |
| `data-slot-active`      | `'true'` 或 `'false'`  | 设置活动字段样式。                     |
| `data-slot-placeholder` | 已配置的占位符         | 字段为空时提供文本。                   |

这些属性和占位符展示不会持久化到 JSON、序列化 HTML 或剪贴板内容中。

## 自定义 NodeView

```ts
const CustomBlockSlot = BlockSlot.extend({
  addNodeView() {
    return ReactNodeViewRenderer(MySlotView)
  },
})

Slot.configure({ blockSlot: CustomBlockSlot })
```

`ReactNodeViewRenderer` 来自 `@tiptap/react`。JavaScript 和 Vue 使用各自标准的 Tiptap NodeView API。

### 约定

- 保留规范的节点名称、`id`/`config` 属性、内容表达式以及 defining/isolating 行为。
- 只通过 `Slot` 注册定制实例。实例在编辑器创建时固定。
- 提供一个可编辑的 `contentDOM`，或框架的 `NodeViewContent` 等价物。
- 让 Tiptap 渲染文档内容。不要从 `node.content` 再渲染一份副本。
- 将控件和标签标记为不可编辑。通过命令执行编辑。
- 行内包装器和内容容器必须使用兼容行内布局的元素，例如 `span`。
- 自定义视图负责可见标签和占位符。默认占位符文本不会添加到自定义视图。
- 保留选区、嵌套编辑、IME 和光标行为。不要吞掉必要的内容事件或变更。

有关框架 API，请参阅 [Tiptap NodeView](/editor/extensions/custom-extensions/node-views)。

## 验证和权限更新

当只有属性发生变化时，使用 [`subscribeSlotViewUpdates`](/composable-docs/slots/api-reference/utilities#subscribeslotviewupdates) 刷新 UI。

```ts
const unsubscribe = subscribeSlotViewUpdates({ editor, onUpdate: refresh })
// When disposing the view:
unsubscribe()
```

- 从 `editor.storage.slot` 读取快照、活动字段和验证状态。
- 导入的 ID 不明确时，使用 `getPos()` 和条目位置。
- 使用 `editor.can()` 检查命令可用性，并使用内容保护查询获取解释。
- 只渲染当前验证结果。显示消息或内容前应用读取权限。
- 挂载视图不会开始验证。

## HTML 序列化

- `addNodeView` controls the editor UI; `renderHTML` controls exported HTML.
- 对于内容槽节点（`BlockSlot` 和 `InlineSlot`），自定义 `renderHTML` 必须保留 3 个序列化属性和 1 个内容槽。
- Generate attributes from the current Node with proper escaping.
- Custom `parseHTML` must preserve IDs and complete configuration. Keep the default parser as a fallback.
- Malformed configuration JSON in HTML becomes `config: null` and produces a validation issue.
- UI controls, placeholders and validation messages belong to the NodeView, not exported content.

## 值槽 NodeViews

通过 `addNodeView` 自定义 `BlockValueSlot` 或 `InlineValueSlot`。这些叶节点没有 `contentDOM` 或 `NodeViewContent`。保持其包装不可编辑，并在其中使用原生控件或框架组件。请参阅[价值槽指南](/composable-docs/slots/guides/value-slots#mix-custom-and-default-nodeviews) 以获得完整的演示。

### `createSlotValueController`

```ts
const slot = createSlotValueController({ editor, getPos })
```

接受 `Editor` 和 NodeView 的实时 `getPos: () => number | undefined` 回调。不需要框架依赖。

- `getState(): SlotValueState`：具有 `value: JsonValue`、`config: SlotConfig | null`、`editable: boolean` 和 `available: boolean` 的稳定不可变快照。
- `getValue(): JsonValue`：最新可读值；不可用时 `null`。
- `setValue(value: JsonValue): boolean`：受保护的命令；当不可用、受保护、不明确或受变量控制时为 false。
- `subscribe(listener: () => void): () => void`：状态变化时通知；返回取消订阅函数。显式读取初始状态。最后一个订阅者取消订阅后，编辑器侦听器将被删除。
- `focus(): void`：当控件获得焦点时选择可读值节点。它不会移动 DOM 焦点。
- `destroy(): void`：释放订阅并阻止进一步写入。

快照引用仅在其属性发生变化时才会发生变化，因此适合 React 的 `useSyncExternalStore`。当其他使用者仍在使用控制器时，请勿销毁该控制器。丢失或不可读的字段具有 `available: false`，并且不会公开其值或配置。

### `createDefaultSlotValueView`

接受标准 `NodeViewRendererProps` 并返回完整的 ProseMirror `NodeView`。对于应保留内置控件的字段，在 `addNodeView` 内调用它。它永远不会再调用您的渲染器。

默认视图管理事件、组合、值更新、权限更改和处置。当输入类型更改时它会重新创建。当配置更改需要不同的渲染器时，自定义视图还必须从 `update` 返回 false。

### 值 HTML

值节点序列化 `data-slot-kind`、`data-slot-mode="value"`、`data-slot-id`、`data-slot-config` 和 `data-slot-value`。配置和值使用转义 JSON。导出的 HTML 包含静态值表示，没有内容漏洞或交互式控件。自定义值槽序列化必须保留这些属性而不添加内容漏洞。

## Redacted content

内容保护会使用自己的[隐藏内容渲染器](/composable-docs/content-protection/api-reference/rendering)替换被隐藏的节点。原始 Slot NodeView 不会继续挂载。

可读取的父节点可能包含被隐藏的子节点。其自定义控件不得在其他位置显示这些子节点的文本、属性或 JSON。完整源文档仍保留在客户端内存中。
