此示例使用[内容保护](/composable-docs/content-protection/getting-started/overview)限制用户可以编辑的内容。用户可以向表格添加和删除行并编辑其中的内容，但不能编辑表格外的内容、添加列或编辑表头。

此演示使用 Slots 将表格单元格定义为字段：每个表格字段都包含一个可以填入内容并在之后验证的 Slot。
