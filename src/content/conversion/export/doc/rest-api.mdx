## 导出 DOC

`POST /v2/convert/export/doc`

`/v2/convert/export/doc` 端点将 Tiptap JSON 文档转换为 DOC 格式。发送包含文档 JSON 的 `POST` 请求，即可获得可下载的 DOC 文件。

### 示例（cURL）

```bash
curl --output document.doc -X POST "https://api.tiptap.dev/v2/convert/export/doc" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello World\"}]}]}"
    }'
```

<Callout title="需要订阅" variant="warning">
    此端点需要有效的 Tiptap 订阅。详情请参阅我们的 <a href="https://tiptap.dev/pricing" target="_blank" rel="noopener noreferrer">定价页面</a>。
</Callout>

### 必填请求头

| 名称            | 描述                                                                                                                               |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `Authorization` | 用于验证请求的 JWT 令牌。示例：`Bearer your-jwt-token`                                                                                   |
| `Content-Type`  | 必须为 `application/json`                                                                                                                 |

### 请求体

| 名称                 | 类型     | 描述                                                            | 默认值      |
| -------------------- | -------- | ---------------------------------------------------------------------- | ----------- |
| `doc`                | `String` | Tiptap JSON document as a string                                       | `N/A`       |
| `exportType`         | `string` | The expected export type                                               | `blob`      |
| `styleOverrides`     | `Object` | Style overrides                                                        | `{}`        |
| `pageSize`           | `Object` | Page size configuration                                                | `undefined` |
| `pageMargins`        | `Object` | Page margins configuration                                             | `undefined` |
| `headers`            | `Object` | Page header configuration                                              | `undefined` |
| `footers`            | `Object` | Page footer configuration                                              | `undefined` |
| `tableOverrides`     | `Object` | Table-level rendering overrides forwarded to the DOCX step             | `undefined` |
| `paragraphOverrides` | `Object` | Paragraph-level rendering overrides forwarded to the DOCX step         | `undefined` |
| `textRunOverrides`   | `Object` | Text run rendering overrides forwarded to the DOCX step                | `undefined` |
| `tableCellOverrides` | `Object` | Table cell rendering overrides forwarded to the DOCX step              | `undefined` |
| `imageOverrides`     | `Object` | Image rendering overrides forwarded to the DOCX step                   | `undefined` |
| `headerFooterOverrides` | `Object` | Per-field overrides scoped to header/footer content (same five keys as the element overrides). See [Element Overrides](#element-overrides). | `undefined` |
| `placeholders` | `Object \| false` | 页眉/页脚中页码标记的重命名映射 (`{ page?, total? }`)，与 `Pages.configure({ placeholders })` 匹配。适用于每种槽形状：纯文本、字符串化 Tiptap JSON 或 Tiptap JSON 对象。传递 `false` 以禁用替换。请参阅[自定义代币名称](/conversion/export/docx/rest-api#custom-token-names-placeholders)。 | `undefined` |
| `customNodeDsl` | `Object` | [Custom-node DSL](/conversion/export/docx/custom-nodes-dsl) rules for rendering custom Tiptap nodes into the exported file. | `undefined` |

#### Page Size Configuration

The `pageSize` object allows you to customize the dimensions of your exported DOC document:

| Property | Type     | Description                                                                                         | Default    |
| -------- | -------- | --------------------------------------------------------------------------------------------------- | ---------- |
| `width`  | `string` | The width of the page. Must be a positive number followed by a valid unit (cm, in, pt, pc, mm, px). | `"21.0cm"` |
| `height` | `string` | The height of the page. Must be a positive number followed by a valid unit (cm, in, pt, pc, mm, px).| `"29.7cm"` |

#### Page Margins Configuration

The `pageMargins` object allows you to customize the margins of your exported DOC document:

| Property | Type     | Description                                                                                                       | Default  |
| -------- | -------- | ----------------------------------------------------------------------------------------------------------------- | -------- |
| `top`    | `string` | The top margin of the page. Can be negative. Must be a number followed by a valid unit (cm, in, pt, pc, mm, px).  | `"1.0cm"`|
| `bottom` | `string` | The bottom margin of the page. Can be negative. Must be a number followed by a valid unit (cm, in, pt, pc, mm, px).| `"1.0cm"`|
| `left`   | `string` | The left margin of the page. Must be a positive number followed by a valid unit (cm, in, pt, pc, mm, px).         | `"1.0cm"`|
| `right`  | `string` | The right margin of the page. Must be a positive number followed by a valid unit (cm, in, pt, pc, mm, px).        | `"1.0cm"`|

#### Headers Configuration

The `headers` object allows you to customize the headers of your exported DOC document:

| Property            | Type      | Description                                                                                                          |
| ------------------- | --------- | -------------------------------------------------------------------------------------------------------------------- |
| `evenAndOddHeaders` | `boolean` | Whether to use different headers for odd and even pages                                                              |
| `differentFirstPage` | `boolean` | Whether to use a different header on the first page. When `true`, the `first` value is used on page one instead of `default`. |
| `default` | `string \| Object` | 每页上的标准默认页眉，或激活 `evenAndOddHeaders` 时奇数页上的页眉。接受纯文本、字符串化 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `first` | `string \| Object` | 第一页上的标题。仅当 `differentFirstPage` 设置为 `true` 时使用。接受纯文本、字符串化 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `even` | `string \| Object` | 激活 `evenAndOddHeaders` 选项时偶数页上的页眉。接受纯文本、字符串化 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |

<Callout title="接受的槽值">
  每个标头值可以是以下三种形状之一：

- A **纯文本字符串。** 生成简单的无样式标头。
- A **字符串化 Tiptap JSONContent。** 启用丰富的格式，例如粗体、斜体和链接。使用 `JSON.stringify(yourHeaderDoc)` 生成它。
- A **Tiptap JSONContent 对象。** 相同的丰富内容，作为请求正文中的嵌套 JSON 对象发送，而不对其进行字符串化。

在 JSON 请求正文中，对象必须包含 `type` 字段，无效形状将返回 `400 Bad Request`。

</Callout>

#### 页脚配置

`footers` 对象允许您自定义导出 DOC 文档的页脚：

| Property            | Type      | Description                                                                                                          |
| ------------------- | --------- | -------------------------------------------------------------------------------------------------------------------- |
| `evenAndOddFooters` | `boolean` | Whether to use different footers for odd and even pages                                                              |
| `differentFirstPage` | `boolean` | Whether to use a different footer on the first page. When `true`, the `first` value is used on page one instead of `default`. |
| `default` | `string \| Object` | 每页上的标准默认页脚，或激活 `evenAndOddFooters` 时奇数页上的页脚。接受纯文本、字符串化 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `first` | `string \| Object` | 第一页的页脚。仅当 `differentFirstPage` 设置为 `true` 时使用。接受纯文本、字符串化 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `even` | `string \| Object` | 激活 `evenAndOddFooters` 选项时偶数页上的页脚。接受纯文本、字符串化 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |

<Callout title="接受的槽值">
  每个页脚值可以是与页眉值相同的三种形状之一：纯文本字符串、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。在 JSON 请求正文中，对象必须包含 `type` 字段，无效形状将返回 `400 Bad Request`。
</Callout>

### 元素覆盖

DOC 生成会经过 DOCX 管线，因此在发送 Tiptap JSON 时，`/export/docx` 支持的那五种相同元素覆盖也同样适用于这里。通过 `docxFile` 上传预先生成的 DOCX 时，它们**不会生效**。

<ElementOverridesRestApi />

#### 结合多个元素覆盖的 cURL 示例

```bash
curl --output document.doc -X POST "https://api.tiptap.dev/v2/convert/export/doc" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"DOC with element-level overrides\"}]}]}",
      "paragraphOverrides": {
        "spacing": { "before": 200, "after": 200 }
      },
      "textRunOverrides": {
        "font": "Arial",
        "size": 24
      }
    }'
```

### 自定义页面布局示例

```bash
curl --output document.doc -X POST "https://api.tiptap.dev/v2/convert/export/doc" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello World\"}]}]}",
      "pageSize": {
        "width": "210mm",
        "height": "297mm"
      },
      "pageMargins": {
        "top": "20mm",
        "bottom": "20mm",
        "left": "15mm",
        "right": "15mm"
      }
    }'
```

### 响应

成功时，API 返回 DOC 文件的二进制下载：

- **状态**：`200 OK`
- **Content-Type**：`application/msword`
- **Content-Disposition**：`attachment; filename=export-{timestamp}.doc`

### 错误响应

| 状态码 | 代码                             | 描述                             |
| ------ | -------------------------------- | -------------------------------- |
| 400    | `NO_DOCUMENT_PROVIDED`           | 请求体中未提供文档               |
| 422    | `FAILED_TO_PARSE_DOCX_FILE`      | 解析 JSON 输入失败               |
| 422    | `FAILED_TO_EXPORT_DOC_FILE`      | 导出中间格式失败                 |
| 422    | `FAILED_TO_CONVERT_DOCX_TO_DOC`  | 转换为 DOC 失败                  |
