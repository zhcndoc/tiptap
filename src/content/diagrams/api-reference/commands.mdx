```ts
editor.commands.updateChartSpec({ spec: { type: 'area', stacked: true } })
editor.chain().focus().insertDiagramInput({ type: 'pie' }).run()
```

## 每个命令的行为方式

采用 `pos` 的命令作用于图表或流程图的该位置。如果没有 `pos`，则作用于所选的一个。当没有任何操作时，它返回 `false` 并且不进行任何更改。

您永远不需要命令来读取图表或流程图。读取它们的函数位于 [`editor.storage.diagrams`](/diagrams/api-reference/storage).
